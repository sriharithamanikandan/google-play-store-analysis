# Google Play Store Data Analysis

## Project Overview

This project analyzes Google Play Store applications and user reviews using Python. It explores app categories, ratings, pricing, installations, and review sentiment.

## Objectives

* Analyze app categories and ratings.
* Compare free and paid applications.
* Explore app size and installation patterns.
* Analyze user review sentiment.
* Create charts and an interactive visualization.

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* TextBlob
* Plotly
* Google Colab

## Project Files

* `cleaned_googleplaystore_apps.csv` — cleaned app dataset.
* `cleaned_googleplaystore_reviews.csv` — cleaned user review dataset.
* `outputs/` — generated charts and interactive visualization.
* `Google_Play_Store_Analysis.ipynb` — analysis notebook, once uploaded.

## Dataset

Source: [Google Play Store Apps and Reviews Dataset](https://www.kaggle.com/datasets/lava18/google-play-store-apps)

## Key Analysis

* App category distribution
* Ratings distribution
* Average ratings by category
* Free vs. paid applications
* Review sentiment analysis
* Interactive category visualization
